# PocketJS on i.MX6UL

Embedded Linux port project for coffee-machine displays at **1024×600** and **1024×800**.

Implementation roadmap: [#1](https://github.com/hvritual/ui/issues/1). Current work: [P0 toolchain and ABI validation](https://github.com/hvritual/ui/issues/2).

This repository is a new port workspace, not an existing production UI. Cross-compilation and QEMU smoke tests must not be presented as physical-board compatibility or display performance evidence. Device control, connectivity and OTA services remain outside this port's ownership.
